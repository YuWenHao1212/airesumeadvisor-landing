#### 2.1 Login to Azure CLI

```bash

# If not logged in
az login

# Set correct subscription
az account set --subscription "5396d388-8261-464e-8ee4-112770674fba"
```

#### 2.2 Create App Service Plan

```bash
az appservice plan create \
  --name airesumeadvisor-plan \
  --resource-group airesumeadvisorfastapi \
  --location japaneast \
  --sku B1
```

**Notes:**
- `B1` = Basic tier (~$13/month)
- Same resource group as backend API
- `japaneast` for consistency with other resources

#### 2.3 Create Web App

```bash
az webapp create \
  --name airesumeadvisor-landing \
  --resource-group airesumeadvisorfastapi \
  --plan airesumeadvisor-plan \
  --runtime "NODE:18-lts"
```

**Expected Output:**
- Default URL: `https://airesumeadvisor-landing.azurewebsites.net`

#### 2.4 Configure Application Insights

First, get the Instrumentation Key from existing App Insights:

```bash
# Get instrumentation key
az monitor app-insights component show \
  --app azure-container-api-insights-v3 \
  --resource-group airesumeadvisorfastapi \
  --query instrumentationKey \
  --output tsv
```

Then configure the Web App:

```bash
az webapp config appsettings set \
  --name airesumeadvisor-landing \
  --resource-group airesumeadvisorfastapi \
  --settings \
    APPINSIGHTS_INSTRUMENTATIONKEY=<key-from-above> \
    APPLICATIONINSIGHTS_CONNECTION_STRING=<connection-string> \
    ApplicationInsightsAgent_EXTENSION_VERSION=~3
```

### Phase 3: GitHub Actions Update

#### 3.1 Update Workflow File

Create/update `.github/workflows/azure-webapp.yml`:

```yaml
name: Deploy to Azure App Service

on:
  push:
    branches: [main]
  workflow_dispatch:

env:
  AZURE_WEBAPP_NAME: airesumeadvisor-landing
  AZURE_WEBAPP_PACKAGE_PATH: './dist'
  NODE_VERSION: '18.x'

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: Build
        run: npm run build

      - name: Deploy to Azure Web App
        uses: azure/webapps-deploy@v2
        with:
          app-name: ${{ env.AZURE_WEBAPP_NAME }}
          publish-profile: ${{ secrets.AZURE_WEBAPP_PUBLISH_PROFILE }}
          package: ${{ env.AZURE_WEBAPP_PACKAGE_PATH }}
```

#### 3.2 Add GitHub Secrets

1. Go to GitHub repo → Settings → Secrets and variables → Actions
2. Add new secret: `AZURE_WEBAPP_PUBLISH_PROFILE`

Get publish profile from Azure:

```bash
az webapp deployment list-publishing-profiles \
  --name airesumeadvisor-landing \
  --resource-group airesumeadvisorfastapi \
  --xml
```

Copy the entire XML output and paste as secret value.

### Phase 4: DNS Configuration (GoDaddy)

#### 4.1 Add Bubble.io subdomain

In GoDaddy DNS Management:

| Type | Name | Value | TTL |
|------|------|-------|-----|
| CNAME | app | `airesumeadvisor.bubbleapps.io` | 600 |

#### 4.2 Update main domain to Azure

First, get Azure verification record:

```bash
az webapp show \
  --name airesumeadvisor-landing \
  --resource-group airesumeadvisorfastapi \
  --query "hostNames" \
  --output tsv
```

In GoDaddy DNS Management:

| Type | Name | Value | TTL |
|------|------|-------|-----|
| A | @ | (Azure IP address) | 600 |
| TXT | asuid | (Azure verification ID) | 600 |
| CNAME | www | `airesumeadvisor-landing.azurewebsites.net` | 600 |

#### 4.3 Configure Custom Domain in Azure

```bash
az webapp config hostname add \
  --webapp-name airesumeadvisor-landing \
  --resource-group airesumeadvisorfastapi \
  --hostname airesumeadvisor.com

az webapp config hostname add \
  --webapp-name airesumeadvisor-landing \
  --resource-group airesumeadvisorfastapi \
  --hostname www.airesumeadvisor.com
```

#### 4.4 Enable HTTPS

```bash
# Create managed certificate
az webapp config ssl create \
  --name airesumeadvisor-landing \
  --resource-group airesumeadvisorfastapi \
  --hostname airesumeadvisor.com

# Bind certificate
az webapp config ssl bind \
  --name airesumeadvisor-landing \
  --resource-group airesumeadvisorfastapi \
  --certificate-thumbprint <thumbprint> \
  --ssl-type SNI
```

Or use Azure Portal:
1. App Service → Custom domains
2. Add custom domain
3. Add binding → Create App Service Managed Certificate
