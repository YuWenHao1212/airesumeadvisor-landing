# Daily Development Log - 2025-12-20

## Goal: Sign Up Source Tracking Implementation

---

## Summary

Implemented `?source=landing` parameter for all CTA links to track user acquisition from Landing Page. Also migrated from legacy Bubble.io URL format to new Web App path structure.

---

## Feature Details

### Issue Reference

`docs/issues/FEATURE_SIGNUP_SOURCE_TRACKING_20251220.md`

### Background

Web App has implemented `signUpSource` field to track user registration sources:
- `webapp` - Direct registration from Web App
- `extension` - Registration from Chrome Extension
- `landing` - Registration from Landing Page (this implementation)

---

## Changes Made

### `src/config/links.ts`

| Item | Before | After |
|------|--------|-------|
| Variable name | `BUBBLE_APP_URL` | `WEB_APP_URL` |
| Env variable | `PUBLIC_BUBBLE_APP_URL` | `PUBLIC_WEB_APP_URL` |
| signup | `?function=Signup` | `/auth/signup?source=landing` |
| login | `?function=Login` | `/auth/login` |
| getStarted | `?function=Signup` | `/auth/signup?source=landing` |
| tryFree | `?function=Signup` | `/auth/signup?source=landing` |
| dashboard | `/main` | `/app/dashboard` |
| buyDaily | `?function=Signup&plan=daily` | `/auth/signup?source=landing` |
| buyWeekly | `?function=Signup&plan=weekly` | `/auth/signup?source=landing` |
| pricing | `?function=Signup` | `/auth/signup?source=landing` |

### URL Path Migration

| Feature | Old (Bubble.io) | New (Web App) |
|---------|-----------------|---------------|
| Sign Up | `?function=Signup` | `/auth/signup` |
| Login | `?function=Login` | `/auth/login` |
| Dashboard | `/main` | `/app/dashboard` |
| Pricing | N/A | `/app/pricing` |
