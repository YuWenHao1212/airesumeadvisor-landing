### 3. Referral Tracking System

**Problem Solved**: Referral code was lost when users clicked "Add to Chrome" because Chrome Web Store is a different domain.

**Solution**:
- Created `/install-extension` relay page
- Uses client-side JavaScript (Astro SSG limitation)
- Sets cookie on `.airesumeadvisor.com` domain before redirecting

**Flow**:
```
Landing Page (?ref=ABC123)
    ↓ setReferralCode() stores to localStorage + Cookie
    ↓ updateCtaLinks() appends ?ref= to all CTAs
User clicks "Add to Chrome" (opens new tab)
    ↓
/install-extension?ref=ABC123
    ↓ JS reads ?ref=, sets cookie, redirects
Chrome Web Store → User installs
    ↓
Extension OAuth → app.airesumeadvisor.com
    ↓ Backend reads cookie → records referredBy
```

### 4. UX Improvements

- "Add to Chrome" button now opens in new tab (`target="_blank"`)
- Industry best practice: keeps Landing Page available for continued conversion

## Technical Notes

### Astro SSG Limitation

Astro runs in Static Site Generation mode. Server-side features like `Astro.cookies.set()` do NOT work at request time - they run at build time.

**Solution**: Use client-side JavaScript for dynamic operations:
```javascript
// In install-extension.astro
const ref = new URLSearchParams(window.location.search).get('ref');
document.cookie = `referral_code=${ref}; Domain=.airesumeadvisor.com; ...`;
window.location.href = chromeWebStoreUrl;
```

### Cookie Configuration

```
Name: referral_code
Domain: .airesumeadvisor.com
Path: /
Max-Age: 7 days
SameSite: Lax
Secure: true
```
